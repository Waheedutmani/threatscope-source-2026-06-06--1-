# ThreatScope - AI-Powered Vulnerability Scanner

## Overview
ThreatScope is a comprehensive cybersecurity vulnerability assessment platform built with Next.js 16, React 19, TypeScript, and Tailwind CSS 4.

## Tech Stack
- Next.js 16 (App Router), React 19, TypeScript 5, Tailwind CSS 4
- Three.js, Framer Motion, Recharts, Zustand 5
- z-ai-web-dev-sdk, Prisma 6 + SQLite

## Getting Started
```bash
npm install && npm run dev
```
